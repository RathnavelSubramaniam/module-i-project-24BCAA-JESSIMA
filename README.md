# Stock Market Sentiment Analysis

## Project Description

This project uses Artificial Intelligence (AI) and Natural Language Processing (NLP) to analyze stock market news. The model predicts whether a news article has a **positive**, **negative**, or **neutral** sentiment. Different embedding techniques and machine learning models are compared to find the best approach for sentiment classification.

## Features

* Stock market news sentiment analysis
* Text preprocessing and feature extraction
* Word2Vec and Sentence Transformer embeddings
* Random Forest and Neural Network models
* Model evaluation using Accuracy, Precision, Recall, F1-Score, and Confusion Matrix

## Dataset

The dataset contains stock market news articles along with stock price information.

**Columns:**

* Date
* News
* Open
* High
* Low
* Close
* Volume
* Label (Sentiment)

## Project Workflow

1. Import libraries
2. Load the dataset
3. Perform data preprocessing
4. Explore the data using EDA
5. Generate text embeddings
6. Train machine learning and deep learning models
7. Evaluate model performance
8. Compare the models and select the best one

## Evaluation Metrics

* Accuracy
* Precision
* Recall
* F1-Score
* Confusion Matrix

## Conclusion

This project shows how AI and NLP can be used to understand the sentiment of stock market news. Comparing different embedding methods and models helps identify the approach that gives better prediction performance.
